# juanmartinrios00.github.io

Portfolio de Juan Martín Rios. HTML, CSS y JS a mano, sin build: se publica directo con GitHub Pages.

- `index.html`: estructura y secciones.
- `styles.css`: estilos (colores y tipografías en `:root`).
- `main.js`: contenido (proyectos, stack, idiomas, experiencia, textos ES/EN) y las interacciones.

Para cambiar un texto o sumar un proyecto, editá los arrays al principio de `main.js`.
